## ブラウザ確認

1. 探索 → ノード選択 → タイムライン巻き戻し → JSON保存。
2. 成分閲覧 → 実験作成 → プレビュー → 確定 → 演算 → 距離 → 3D表示 → 実験破棄。
3. OOVの入力近傍へのエラー表示と、禁止演算を送信できないこと。
4. 一時停止で開始 → 1展開 → キャンセル。390px幅で横あふれがないこと。
5. 初回SSE通信を中断し、復元した連番・イベント数とサーバーを照合。

## 学習済みモデルの確認

`python -m scripts.validate_trained_model` で、プロジェクト独自のCC0コーパスからGensim Word2Vecを学習し、
一時ファイルへtext/binaryで出力して実APIで検証しています。アプリの機能として再学習を提供するものではありません。
モデルのハッシュ、学習条件、経路、チェック結果は [trained-validation.json](trained-validation.json)。
小さな検証用モデルであり、第三者の事前学習モデルの言語品質・大規模利用を検証したという意味ではありません。

## 性能と未達・仕様差分

小型fixtureのp95計測値と環境は [benchmark.json](benchmark.json) に記録しています。
health / 候補 / 成分 / 類似語はいずれも仕様の小型fixture目標以内でした。

5,000ノード・4,999辺の表示で、描画を200要素ずつに分割し、パン・ズーム・ボタン応答を確認しました。
CPU/RAM・描画時間・フレーム間隔・操作応答は [performance-5000.json](performance-5000.json)。
10,000語×32次元の独自人工モデルで1秒間探索を進めてから中止し、2秒以内の停止と、その後に展開が増えないことを確認しました。
記録は [performance-search.json](performance-search.json) です。

メモリ保持イベントを12件に下げたテストでは、スナップショットとSQLiteへの退避後も探索が成功し、
過去の任意の連番から欠落なく履歴が復元されることを確認しています。
ブラウザの6シナリオも12件の保持設定で通過しています。配信用サーバーは既定の100,000件に戻しています。
UIのモデル再読み込みも非同期ジョブで、進捗・協調キャンセルに対応します。

残る適用範囲・任意構成の制約は次のとおりです。

- 第三者の大規模な事前学習モデルの言語品質・性能は未検証です。検証済みモデルは37語の人工fixture、78語の独自学習モデル、性能用10,000語の人工モデルです。
- ANNは未追加です。この規模の計測に対する必須性を確認していないため、exactとして明示しています。UMAPも任意依存として未有効化です。
- モデル検証/読み込みは同一プロセスでメモリ上限を検証します。射影は別プロセスです。OSによる厳密なメモリ隔離は提供しません。
- リモートCIは未実行です。設定を同梱し、相当する品質ゲートをローカルで検証しています。
