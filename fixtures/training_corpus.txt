猫 と 犬 は 人 と 暮らす 動物 です
猫 は 家 で 眠り 犬 は 庭 で 遊ぶ
犬 と 猫 は ペット として 人 に 親しまれる
動物 は 森 や 山 や 川 に 住む
森 の 自然 は 動物 と 植物 を 育てる
植物 は 太陽 の 光 を 受けて 育つ
太陽 の 光 は 地球 の 生命 を 支える
生命 は 地球 の 自然 の 中 で 続く
地球 は 太陽 の 周り を 回る 星 です
月 は 地球 の 周り を 回る
空 に 太陽 が 昇り 夜 に 星 が 見える
夜 の 空 に 月 と 星 が 輝く
星 と 銀河 は 広い 宇宙 に ある
宇宙 には 地球 や 太陽 や 月 が ある
自然 を 観察 して 生命 と 宇宙 を 学ぶ
人 は 本 を 読み 言葉 と 世界 を 学ぶ
言葉 の 関係 を 調べて 新しい 発見 を する
東京 は 日本 の 首都 です
北京 は 中国 の 首都 です
パリ は フランス の 首都 です
日本 の 東京 と 中国 の 北京 は 都市 です
フランス の パリ は 都市 です
王 と 女王 は 国 を 治める
男 と 女 は 人 として 社会 で 暮らす
